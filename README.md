# 기출지우개 : 2027 사회조사분석사 2급

공인중개사 앱 '기출지우개 : 공인중개사 2027'(`생활\공인중개사 기출\앱\배포2`)의 사본을 사회조사분석사 2급 필기용으로 고친 것(11-05). 카드를 넘기는 방식(옳은 말 O/X·예/아니오·계산 번호, 서로 다른 날 3번 맞히면 지움, 지운 카드 하루 3장 검사, 되돌리기, 켤 때 첫 화면, 기기 간 동기화)은 그대로다.

- 주소: https://jjangguss-prog.github.io/gichul-jiugae-sajo/ (11-05 올림, 저장소 jjangguss-prog/gichul-jiugae-sajo)
- 홈 화면 이름 '기출지우개 사조사'. 공인중개사 앱(파랑)과 구별되게 첫 화면·위쪽 막대(theme-color)·아이콘 바탕이 초록(#1f7a5a, 어두운 화면 #133d2f).
- 과목 셋, 한 시험(1차·2차 없음): 조사설계(조사방법과 설계 30문항)·조사관리(조사관리와 자료처리 30문항)·통계(통계분석과 활용 40문항). 새 카드는 조사설계 → 조사관리 → 통계 순서로 한 과목씩, 복습은 섞어서.
- 예상 점수는 과목마다 100점 만점(과목 40점 미만 과락, 세 과목 평균 60점 이상 합격선). 실전은 과목·회차마다, 점수 = 맞힌 수 ÷ 문항 수 × 100, 시간은 150분 ÷ 100문항 기준(30문항 45분, 40문항 60분).
- 시험일: 2027년 1회 필기 2027-02-06(토)로 잡아 둠(`index.html`의 `EXAM_DATE` 한 줄). 2027년 국가기술자격 시행계획(2026년 11월 하순 공고 예정)이 나오면 그 줄만 바꾼다. 1회 필기는 CBT라 기간 중 고른 날에 본다.
- 회차: cards.json `Q.round`는 연도×10 + 회(20211 = 2021년 1회, 20201 = 2020년 1·2회 통합). 화면에는 `roundName()`이 '2021년 1회'로 바꿔 보인다.
- 자료 탭은 논점·실전만. 공인중개사 앱의 패턴·개념서·타시험·듣기와 조문 머리(johead.json)는 뺐고 받지도 않는다. 해설의 조문 번호 회색·기간·금액 숫자 굵게(법령용)도 뺐다.
- 기록은 공인중개사 앱과 따로 둔다. 같은 주소(jjangguss-prog.github.io) 아래라 기기 저장소를 함께 쓰기 때문에 저장 이름은 모두 `jiugaesa`·`jiugaesa-*`, 동기화 파일은 `jiugaesa-sync.json`, 서비스워커 캐시는 `jiugaesa-v1`이고 옛 캐시 지우기도 `jiugaesa-`로 시작하는 것만 한다(공인중개사 앱의 `jiugae-…`·`jiugae2-…`는 건드리지 않음).
- 설정 → 기기 간 동기화 → **공인중개사 앱에 넣은 토큰 쓰기**: 그 기기 공인중개사 앱의 GitHub 토큰만 칸에 넣는다(gist 번호는 안 읽음). 공인중개사 앱 기록을 가져오는 기능은 없다.
- 카드 자료(`cards.json`·`cards.ver`)는 `..\..\카드만들기.py`가 만든다. 앱 껍데기는 `index.html`·`sw.js`·`manifest.webmanifest`·`icon.svg`·`icon-192.png`·`icon-512.png`(PNG는 PyMuPDF로 icon.svg에서 그림).
- 확인(11-05, 로컬 Playwright, 시험용 카드 18장): 화면 사진은 `..\확인\`.
- 문제: 2017~2021년 사회조사분석사 2급 필기 공개 기출(한국산업인력공단)의 논점을 바탕으로 이 앱을 위해 새로 쓴 문장입니다. 원문이 아닙니다. 근거·해설도 직접 작성.
